Patrones GoF I — Factory Method & Strategy

🏭 Factory Method (Creacional)
Desacopla la creación de vehículos de su uso. Ningún componente llama a new Moto() directamente.
class VehiculoFactory {
public:
  virtual ~VehiculoFactory() = default;
  virtual std::unique_ptr<Vehiculo>
    crear(const std::string& id,
          const std::string& placa) const = 0;
};

class MotoFactory : public VehiculoFactory {
public:
  std::unique_ptr<Vehiculo>
    crear(const std::string& id,
          const std::string& placa) const override {
    return std::make_unique<Moto>(id, placa);
  }
};
// También: AutoFactory, CamionFactory
💱 Strategy (Comportamiento)
Calcula la tarifa en tiempo real según el tipo de paquete. Se muestra automáticamente en el formulario de registro.
class IEstrategiaTarifa {
public:
  virtual ~IEstrategiaTarifa() = default;
  virtual double calcular(
    double distKm, double pesoKg) const = 0;
};

// Frágil: 40% de recargo por manejo especial
class TarifaFragilStrategy
    : public IEstrategiaTarifa {
public:
  double calcular(double distKm,
                  double pesoKg) const override {
    return (distKm * 2.5 + pesoKg * 0.8) * 1.4;
  }
};
// También: TarifaEstandarStrategy, TarifaPesadaStrategy
Factory Method desacopla la construcción de objetos de su uso. Strategy permite cambiar el algoritmo de tarifas dinámicamente según el tipo de paquete seleccionado.

Programación Genérica — Templates Propios & RAII

Cola<T> — FIFO Thread-Safe Propia
template <typename T>
class Cola {
public:
  void push(T valor) {
    std::lock_guard<std::mutex> lock(m_mutex);
    m_queue.push(std::move(valor));
  }

  [[nodiscard]] std::optional<T> pop() {
    std::lock_guard<std::mutex> lock(m_mutex);
    if (m_queue.empty()) return std::nullopt;
    T val = std::move(m_queue.front());
    m_queue.pop();
    return val;
  }

  // Extrae el primer elemento que cumpla el predicado
  template <typename Predicate>
  [[nodiscard]] std::optional<T>
    extraerSi(Predicate pred);

private:
  mutable std::mutex m_mutex;
  std::queue<T>      m_queue;
};
Gestión de Memoria RAII
unique_ptr<T> Propietario exclusivo — factorías de vehículos shared_ptr<T> Propiedad compartida — pedidos en flota activa weak_ptr<T> Referencia débil — lista de observers (evita ciclos)
Otros Templates
Repositorio<T,Key>
Almacén asociativo genérico con búsqueda por lambda predicado
Ruta<CoordType>
Cálculo geométrico parametrizado en float o double
✅ 0% punteros crudos con new/delete en la lógica de negocio
Cola T es nuestra estructura de datos central. extraerSi permite a una Moto extraer solo pedidos de menos de 15 kg sin afectar el orden de los demás. Zero new/delete manuales en toda la lógica de negocio.

🔒 Singleton — Meyer's C++17 Thread-Safe

class ServicioRutas {
public:
  // Thread-safe por garantía del estándar C++17

  ServicioRutas& operator=(const ServicioRutas&) = delete;

void SimuladorEntregas::hiloRepartidor(
    std::shared_ptr<Repartidor> rep) {
  while (m_corriendo) {
    std::unique_lock<std::mutex> lock(m_mutex);
    // Duerme hasta que llegue un pedido
    m_condVar.wait(lock, [&] {
      return !m_cola->isEmpty() || !m_corriendo;
    });
    if (!m_corriendo) break;
    // Solo extrae pedidos compatibles
    auto pedido = m_cola->extraerSi([&](auto& p) {
      return rep->puedeAtender(*p);
    });
    lock.unlock();  // liberar antes de entregar
    if (pedido) {
      simularEntrega(rep, *pedido);
      // Round-Robin: ceder turno a otros hilos
      std::this_thread::sleep_for(50ms);
    }
  }
}
Primitivas de Sincronización

Protege la Cola compartida

Despierta todos los conductores ante un pedido nuevo
⚛️
std::atomic<int>

🔗

Parada limpia — garantía deadlock-free
Cada repartidor corre en su propio hilo. notify_all despierta a todos los consumidores. El predicado de extraerSi garantiza que cada repartidor solo tome pedidos compatibles con su vehículo.

Balanceo de Carga & Prevención de Deadlocks

🔄 Round-Robin Cooperativo
Al terminar una entrega, el hilo cede el turno 50 ms:
std::this_thread::sleep_for(50ms);

Esto permite que el otro conductor del mismo tipo tome el siguiente pedido, distribuyendo la carga de forma equitativa sin un scheduler centralizado.
🚫 Reglas Anti-Deadlock
  • Liberar el lock antes de llamar a simularEntrega().
  • Notificar observers fuera del mutex de la lista.
  • thread::join() fuera del lock de simulación.
  • Despacho escalonado (700 ms) entre vehículos.
